# tiny-decode

# Getting Started

First, set up the virtual environment.

```bash
python3 -m venv .venv
. .venv/bin/activate
pip3 install -r requirements.txt
```

Then navigate to [phase0/step0](TODO), and run the following command (you may need to register for a [Modal](https://modal.com/) account, which will take about ~2 minutes).

```bash
modal run ./modal_run.py
```
